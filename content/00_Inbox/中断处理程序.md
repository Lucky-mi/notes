### 一、 宏观全景图：中断处理的三个阶段

我们将整个过程分为三个阶段，其中**最容易考的坑点**在于：哪些是 CPU 自动完成的（称为**中断隐指令**），哪些是操作系统写代码完成的。

---

### 二、 详细拆解：从“检测”到“返回”的每一步

#### 第一阶段：中断响应（硬件接管）—— “中断隐指令”

这一阶段不需要程序员写任何代码，完全由 CPU 内部电路在**指令执行周期结束后**自动完成。这组动作统称为 **“中断隐指令”**。

1. **中断判优：**
    
    - 如果有多个中断源同时申请（比如网卡和键盘同时响），硬件根据优先级排队，选出优先级最高的那个。
        
2. **关中断（Disable Interrupts）：**
    
    - **核心动作：** 将中断允许标志位（IF）置为 0。
        
    - **目的：** 为了保证接下来的“保存断点”动作是原子的，不被打断。如果刚存了一半 PC 又来个中断，堆栈就乱了。
        
3. **保存断点（Save Context - Part 1）：**
    
    - **核心动作：** 将当前的 **PC（程序计数器）** 和 **PSW（程序状态字）** 的值压入系统内核栈。
        
    - _注意：这里只保存了“在哪里停下”和“当时的状态”，并没有保存通用寄存器的数据。_
        
4. **引出中断服务程序（Vectoring）：**
    
    - **核心动作：** 硬件根据中断向量号，查**中断向量表**，取出对应的 ISR 入口地址，送入 PC。
        
    - **结果：** 此时 CPU 的指挥棒已经交到了操作系统手中。
        

#### 第二阶段：中断处理（软件接管）—— “中断服务程序 (ISR)”

从这里开始，执行的是操作系统内核写好的代码。

5. **保存现场（Save Context - Part 2）：**
    
    - **动作：** 使用 `PUSH` 指令，将 CPU 里的**通用寄存器**（如 AX, BX, CX...）的内容全部压栈。
        
    - **原因：** ISR 也是一段程序，它也要用寄存器做加减乘除。如果不先保存原来的值，等 ISR 跑完，原来进程的数据就被覆盖了（“案发现场”被破坏）。
        
6. **执行具体的中断服务（Execute Service）：**
    
    - 这是 ISR 的主体。
        
    - **例子：** 如果是键盘中断，就读取键盘缓冲区的数据放入内存；如果是时钟中断，就检查时间片是否用完，决定是否通过调度器切换进程。
        
7. **恢复现场（Restore Context - Part 2）：**
    
    - **动作：** 服务做完了，使用 `POP` 指令，将堆栈里保存的通用寄存器数据弹回 CPU 寄存器。
        
    - **结果：** 此时 CPU 的通用寄存器恢复到了中断发生前一瞬间的样子。
        

#### 第三阶段：中断返回（硬件接管）—— “中断返回指令”

8. **中断返回（Interrupt Return）：**
    
    - **动作：** 执行特殊的汇编指令（如 x86 的 `IRET`）。
        
    - 这是一条硬件指令，它会原子性地完成以下操作：
        
        - 从栈中弹出 **PSW**（恢复状态，这也意味着**开中断**，因为 PSW 里包含 IF 位）。
            
        - 从栈中弹出 **PC**（恢复断点）。
            
    - **结果：** CPU 下一条指令就跳回了原来被中断的用户程序继续执行，仿佛什么都没发生过。

### 三、 考研 408 必考难点辨析（避坑指南）

为了让你在做选择题时秒杀对手，请务必记清楚这三个 **“谁做的”**：

|**动作步骤**|**执行者**|**备注**|
|---|---|---|
|**1. 关中断**|**硬件**|包含在“中断隐指令”中|
|**2. 保存 PC 和 PSW**|**硬件**|包含在“中断隐指令”中|
|**3. 寻找入口地址**|**硬件**|包含在“中断隐指令”中|
|**4. 保存通用寄存器**|**软件 (OS)**|这是 ISR 的第一步代码|
|**5. 执行业务逻辑**|**软件 (OS)**|ISR 的核心代码|
|**6. 恢复通用寄存器**|**软件 (OS)**|ISR 的收尾代码|
|**7. 恢复 PC 和 PSW**|**硬件**|执行 `IRET` 指令自动完成|

**最经典的考题坑点：**

- **问：** “保存现场”是谁做的？
    
- **答：** 要看它指哪部分。
    
    - 如果指 **PC/PSW**（断点），是**硬件**做的。
        
    - 如果指 **通用寄存器**（数据），是**软件**做的。
        
    - _(但在 408 题目文字表述中，通常默认“保存现场”特指软件保存通用寄存器的过程，而硬件保存 PC 叫“保存断点”。)_

### 四、 形象化总结

想象你在**打游戏（用户程序）**，突然**妈妈喊你吃饭（中断信号）**：

1. **硬件（大脑自动反应）：**
    
    - 听到声音（检测中断）。
        
    - 心里记下游戏打到第几关、血量多少（**硬件保存 PC/PSW**）。
        
    - 把耳朵闭上，暂时不听其他人说话，防止分心（**关中断**）。
        
    - 身体转向餐厅（**寻找向量，跳转**）。
        
2. **软件（你的主观动作）：**
    
    - 把手里的手柄轻轻放在桌子上，确认没掉下去（**软件保存通用寄存器**）。
        
    - 去吃饭（**执行中断服务**）。
        
    - 吃完饭，拿起手柄（**软件恢复通用寄存器**）。
        
3. **硬件（习惯性动作）：**
    
    - 回想起刚才打到第几关（**硬件恢复 PC/PSW**）。
        
    - 张开耳朵（**开中断**）。
        
    - **继续打游戏**。
