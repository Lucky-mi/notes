## 一、 实验内容
1. **生成运动模糊图像**：参考课程的参数设置，编程实现匀速直线运动模糊的退化模型。
2. **维纳滤波复原**：依据PPT第39页的原理，实现参数化的维纳滤波算法，对添加了高斯噪声的模糊图像进行复原，并与直接逆滤波的结果进行对比分析。
## 二、 实验原理
图像复原旨在根据退化的先验知识重建原始图像。依据课程第5章内容，本次实验主要针对**加性噪声下的线性位移不变退化**进行复原。
### 1. 退化模型
根据PPT第6页，图像退化过程在频域表示为：
$$G(u,v) = H(u,v)F(u,v) + N(u,v)$$

其中，$H(u,v)$ 是退化函数，$N(u,v)$ 是加性噪声。
本实验模拟**匀速直线运动模糊**，其退化函数 $H(u,v)$ 采用PPT第34页给出的公式：
$$H(u,v) = \frac{T}{\pi(ua+vb)} \sin[\pi(ua+vb)] e^{-j\pi(ua+vb)}$$
实验参数设置为 $a=b=0.1, T=1$。
### 2. 逆滤波 (Inverse Filtering)
PPT第36页指出，最简单的复原方法是直接逆滤波：
$$\hat{F}(u,v) = \frac{G(u,v)}{H(u,v)} = F(u,v) + \frac{N(u,v)}{H(u,v)}$$
**局限性**：当 $H(u,v)$ 为0或非常小（接近零点）时，噪声项 $\frac{N(u,v)}{H(u,v)}$ 会趋向无穷大。此时，有用信息会被噪声完全淹没，导致复原失败。

### 3. 维纳滤波 (Wiener Filtering)

为了解决逆滤波对噪声敏感的问题，采用最小均方误差（维纳）滤波。根据PPT第39页，其频域解为：
$$\hat{F}(u,v) = \left[ \frac{1}{H(u,v)} \frac{|H(u,v)|^2}{|H(u,v)|^2 + S_\eta(u,v)/S_f(u,v)} \right] G(u,v)$$
在实际应用中，常引入交互式常数 $K$ 来近似信噪比项 $\frac{S_\eta}{S_f}$，公式简化为：
$$\hat{F}(u,v) = \left[ \frac{1}{H(u,v)} \frac{|H(u,v)|^2}{|H(u,v)|^2 + K} \right] G(u,v)$$
经过代数化简，这也是代码中实际使用的形式：
$$\hat{F}(u,v) = \frac{H^*(u,v)}{|H(u,v)|^2 + K} G(u,v)$$
当 $|H(u,v)|^2$ 远小于 $K$ 时（即在退化函数的零点附近），维纳滤波通过 $K$ 限制了分母的大小，从而有效抑制了噪声放大。
## 三、 核心代码实现

### 1. 构建运动模糊退化函数 
```m
[V, U] = meshgrid(1:N, 1:M);
U = U - floor(M/2) - 1; V = V - floor(N/2) - 1; % 中心化
a = 0.1; b = 0.1; T = 1;
uavb = pi * (U*a + V*b) + eps;
H = (T ./ uavb) .* sin(uavb) .* exp(-1j * uavb); % 课本例5.10公式
H = ifftshift(H);

```
### 2. 维纳滤波复原

```
K = 0.02; % 调节参数K，平衡去噪与锐化
% 利用化简后的维纳公式: H* / (|H|^2 + K)
W = conj(H) ./ (abs(H).^2 + K);
f_wiener = real(ifft2(W .* G_noisy));
```

### 结果分析：
1. **运动模糊图像**： 由结果图可见，使用PPT中 $a=b=0.1$ 的参数后，图像出现了明显的对角线方向模糊，文字边缘变得难以辨认。
2. **逆滤波复原结果**： **现象**：复原图像充满了剧烈的颗粒状噪声，完全无法辨认原始内容。 **原因**：由于运动模糊函数 $H(u,v)$ 是Sinc函数形式，存在许多零点。在这些频率点上，逆滤波公式中的分母接近0，导致加性噪声被无限放大（"有用信息被淹没"），验证了逆滤波在有噪环境下的不稳定性。
3. **维纳滤波复原结果**： **现象**：图像得到了较好的恢复，"Digital Image Processing" 文字清晰可读，背景噪声得到了有效控制。 **原因**：维纳滤波引入了参数 $K$。在 $H(u,v)$ 较大的低频区域，滤波器近似于逆滤波，起到了去模糊作用；在 $H(u,v)$ 接近0的高频或零点区域，分母由 $K$ 主导，避免了除零错误，从而在恢复细节的同时抑制了噪声。
## 五、 实验总结
通过本次实验，我得出以下结论：
1. 运动模糊会显著降低图像的高频分量，导致细节丢失。
2. **逆滤波**虽然理论上能完美复原无噪图像，但对噪声极度敏感，在实际有噪系统中几乎不可用。
3. **维纳滤波**通过最小化均方误差，在“去模糊”和“抑噪”之间找到了平衡点。参数 $K$ 的选择至关重要：$K$ 过大图像偏模糊，$K$ 过小则噪声残留明显。本实验中取 $K=0.02$ 获得了较好的视觉效果。
