## [[GPU&CUDA]]
### 🧠 计算机体系结构与异构计算重点 (408/AI架构)

#### 1. 硬件灵活性与效率权衡 (Trade-off)

> [!SUMMARY] 核心结论
> **灵活性 (Flexibility):** CPU > GPU > FPGA > ASIC
> **能效比 (Performance/Watt):** ASIC > FPGA > GPU > CPU
> **开发难度 (Dev Difficulty):** ASIC > FPGA > GPU > CPU

| 类型 | 全称 | 描述 | 特点 | 适用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **CPU** | Central Processing Unit | 通用处理器 | 软件定义，指令集控制，灵活性最高，效率最低。 | 逻辑控制、复杂串行任务 |
| **GPU** | Graphics Processing Unit | 图形处理器 | SIMT 架构，适合大规模并行计算。 | AI 训练/推理、图形渲染 |
| **FPGA** | Field-Programmable Gate Array | 现场可编程门阵列 | 硬件电路可重构，半定制。 | 原型验证、低延迟通信、小批量专用硬件 |
| **ASIC** | Application-Specific Integrated Circuit | 专用集成电路 | 电路物理固化，不可更改。 | 大规模量产的 AI 芯片 (如 TPU)、矿机 |

#### 2. GPU 编程模型与存储层次 (CUDA)

##### 编程模型开源性
* **❌ CUDA:** NVIDIA 私有标准 (闭源)。
* **✅ OpenCL / OpenMP / OpenACC:** 开放标准 (开源/通用)。

##### GPU 存储器速度层级 (Memory Hierarchy)
从快到慢 ($T_{access}$ 延迟递增)：

1.  **Register (寄存器)**
    * *位置:* On-chip (SM 内部)
    * *延迟:* ~0 cycle
    * *范围:* 线程私有 (Thread Private)
2.  **Shared Memory (共享内存)**
    * *位置:* On-chip (SM 内部，用户可控缓存)
    * *延迟:* ~20-30 cycles
    * *范围:* 线程块内共享 (Block Shared)
3.  **Local Memory (局部内存)**
    * *位置:* Off-chip (显存 DRAM，但不仅限于此)
    * *注意:* 名为"Local"，实际很慢。用于寄存器溢出 (Spilling)。
4.  **Global Memory (全局内存)**
    * *位置:* Off-chip (显存 DRAM)
    * *延迟:* ~400-800 cycles
    * *范围:* 全局共享 (Host & Device)

// ❌ 错误示范：缺失同步导致的 RAW 竞争
__global__ void stencil_1d(int *in, int *out) {
    __shared__ int temp[...];
    // 1. 加载数据 (Write to Shared Mem)
    temp[lindex] = in[gindex]; 
    
    // 💀 致命错误：这里缺少了 __syncthreads();
    // 此时其他线程可能还没完成上面的写入操作！
    
    // 2. 读取数据 (Read from Shared Mem)
    // 这是一个 RAW 依赖：必须等别人 Write 完，我才能 Read。
    int result = 0;
    for (...) {
        result += temp[lindex + offset]; // 可能读到脏数据
    }
    out[gindex] = result;
}
