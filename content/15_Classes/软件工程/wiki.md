# Project Summary
本项目旨在开发一个面向大学校园的二手交易平台，专注于解决校园内二手商品交易中的痛点，提供安全、便捷的交易环境，促进校园内的资源循环利用和经济活动。通过用户友好的界面和高效的交易功能，平台力求为在校学生和毕业生提供更好的交易体验。新增加的“产品管理”和“订单交易”模块将进一步增强平台的功能，支持更复杂的交易场景，同时引入了线下交易流程的设计，确保交易的顺利完成。此外，API设计已根据RESTful风格完成，涵盖产品和订单模块的核心功能。

# Project Module Description
## 用户角色分析
本模块分析了在“校园二手交易平台”中涉及的核心用户角色，包括：
- 在校学生-卖家
- 在校学生-买家
- 毕业生
- 新生/低年级学生
- 平台管理员
- 学校宿舍管理人员

## 用户故事
根据用户角色，编写了核心用户故事，涵盖以下场景：
1. 物品发布与管理
2. 浏览与搜索
3. 交易与报价
4. 校园认证与安全

## 需求列表
### 功能性需求
1. **用户模块**
   - 用户注册与认证
   - 用户权限与角色管理
   - 用户信息管理
   - 用户安全设置

2. **商品模块**
   - 商品发布与管理
   - 商品展示与推荐
   - 商品分类管理

3. **交易模块**
   - 交易流程管理
   - 支付与结算
   - 交易状态管理

4. **评价模块**
   - 交易评价
   - 评价内容审核

5. **安全模块**
   - 内容安全审核
   - 交易安全管理

6. **管理模块**
   - 用户管理
   - 内容管理
   - 数据分析

7. **通知模块**
   - 消息通知
   - 短信通知
   - 邮件通知

8. **个性化模块**
   - 用户偏好设置
   - 推荐系统优化

9. **产品管理模块**
   - 商品创建、更新、删除
   - 商品搜索与展示

10. **订单交易模块**
    - 订单创建、确认、支付
    - 订单状态管理

### 非功能性需求
- 性能需求
- 安全需求
- 可用性需求
- 扩展性需求

# File Description Inventory
- **用户角色分析.md**: 该文件详细记录了校园二手交易平台的用户角色及其痛点分析，作为项目开发的重要参考。

- **需求列表.md**: 该文件详细列出了项目的功能性和非功能性需求，作为开发和测试的基础。
- **用例图.md**: 该文件包含PlantUML格式的用例图，描述用户与系统的交互，帮助团队理解系统功能。
- **类图.md**: 该文件包含PlantUML格式的类图，描述系统的类及其关系。
- **时序图.md**: 该文件包含PlantUML格式的时序图，描述交易流程的详细步骤。
- **系统设计.md**: 该文件详细描述了系统的设计理念和架构。
- **数据库设计.md**: 该文件包含数据库结构设计，详细说明表及其关系。
- **文件树.md**: 该文件列出了项目的目录结构及各文件的用途。
- **detailed_class_diagram.plantuml**: 该文件包含产品管理和订单交易模块的详细类图，描述其类及关系。
- **er_diagram.plantuml**: 该文件包含数据库的ER图，描述实体及其关系。
- **offline_transaction_sequence.plantuml**: 该文件包含线下交易过程的时序图，描述交易的各个环节。
- **api_design.md**: 该文件包含产品管理和订单交易模块的RESTful API设计文档，详细描述API的请求和响应格式。
