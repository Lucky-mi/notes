我们可以把 CPU 内部存储的东西分为 **寄存器（Registers）**、**缓存（Cache）** 和 **管理单元（MMU/TLB）** 三大类。
### 1. 寄存器 (Registers)

这是 CPU 内部速度最快、最昂贵的存储单元，通常按“个”来数。它们直接参与指令执行。

#### A. 用户可见寄存器 (通用寄存器)

程序员（汇编语言）可以直接操作的。

- **数据寄存器 (Data Registers)**: 如 x86 的 EAX, EBX 等。用来放临时的计算数据、变量。
    
- **地址寄存器 / 索引寄存器**: 用来存放内存地址的指针，方便计算数组下标等。
    

#### B. 控制与状态寄存器 (Control & Status Registers) ★ 重点

这些决定了 CPU 的“当前状态”和“下一步动作”，操作系统极度依赖它们。

- **程序计数器 (PC / IP - Instruction Pointer)**:
    
    - **存什么**：**下一条**需要执行的指令的内存地址。
        
    - _关联_：CPU 取完一条指令，PC 自动加 1（或者跳到跳转目标），永远指向未来。
        
- **指令寄存器 (IR - Instruction Register)**:
    
    - **存什么**：**当前正在执行**的那条指令的内容（操作码+操作数）。
        
    - _关联_：从内存取出来的指令先放在这，解码器读懂它是在干嘛。
        
- **程序状态字 (PSW / EFLAGS)**:
    
    - **存什么**：当前运算的状态（结果是零吗？溢出了吗？）以及 **CPU 的工作模式**。
        
    - _关键位_：**内核态/用户态标志位**（Kernel/User Mode Bit）。操作系统通过修改这个位来切换权限。
        
- **栈指针 (SP - Stack Pointer)**:
    
    - **存什么**：指向当前栈顶的地址。
        
    - _关联_：你之前问的“栈”，就是靠这个寄存器来标记用到哪了。

### 2. 内存管理相关的硬件 (Memory Management) ★ 你问的核心

这部分硬件专门负责把 **虚拟地址** 变成 **物理地址**。

#### A. MMU (Memory Management Unit)

- **是什么**：它通常是 CPU 里的一个硬件电路模块，不是单纯的存储，但它包含关键的存储部件。
    
- **作用**：所有从 CPU 发出的地址，必须经过 MMU 查表翻译，才能发给内存条。
    

#### B. TLB (Translation Lookaside Buffer, 快表)

- **存什么**：**近期用过的页表项（Page Table Entries）的副本**。
    
- **通俗理解**：它是页表的“缓存”。因为页表存在内存里（很慢），MMU 会把最近查到的“虚拟页号 -> 物理页框号”的映射关系存在 TLB 里。
    
- **位置**：就在 CPU (MMU) 内部。
    
- **速度**：比查内存快几十倍。
    

#### C. 重定位寄存器 / 基址寄存器 (Base Register)

- **存什么**：当前运行进程的**起始物理地址**（或者是页目录表的起始地址，如 x86 的 `CR3` 寄存器）。
    
- **作用**：
    
    - 在**分段机制**下：虚拟地址 + 基址寄存器 = 物理地址。
        
    - 在**分页机制**下：它指向页表在内存中的位置，让 MMU 知道去哪找页表。
        

#### D. 界限寄存器 / 限长寄存器 (Limit Register)

- **存什么**：当前进程占用的内存**长度**（或者段的长度）。
    
- **作用**：**保护**。防止进程越界访问。
    
    - 逻辑：如果（逻辑地址 > 界限寄存器），CPU 直接报错（抛出异常/中断），因为你想访问不属于你的内存。

### 3. 缓存 (Cache)

这是为了弥补 CPU 和 内存（RAM）之间巨大的速度差异。

- **L1 Cache (一级缓存)**:
    
    - 最快，最小。通常分为 **指令缓存 (I-Cache)** 和 **数据缓存 (D-Cache)**。
        
- **L2 Cache**: 稍慢，稍大。
    
- **L3 Cache**: 更慢，更大，通常是多核共享的。
    
- **存什么**：内存中数据的**副本**。CPU 拿数据先找 L1，没有找 L2，再没有找 L3，最后才去 RAM。

### 4. 总结图谱（帮你建立空间感）

你可以想象 CPU 是一个**加工车间**：

1. **工作台 (寄存器)**：
    
    - `AX/BX` 是手边的工具。
        
    - `PC` 是记事本，记着“下一步做第几道工序”。
        
    - `SP` 指着材料堆（栈）的顶部。
        
    - `PSW` 是红绿灯，显示当前是“管理员模式”还是“普通工人模式”。
        
2. **保安室 (MMU)**：
    
    - **基址/界限寄存器**：保安手里的“地界图”，防止你跑到别人的车间去。
        
    - **TLB (快表)**：保安的“常用访客名单”，熟人直接放行，不用去翻厚厚的登记簿（内存里的页表）。
        
3. **临时仓库 (Cache)**：
    
    - 把原材料（内存数据）先搬到车间门口的仓库（L1/L2/L3），随用随取。

### 这一块在考试/面试中的考点：

1. **进程切换切什么？** 主要是切 **寄存器**。把进程 A 的 PC、SP、通用寄存器存回内存（PCB），把进程 B 的这些值从 PCB 载入 CPU。
    
2. **TLB 什么时候刷新？** 进程切换时（切换页表基址）通常需要刷新 TLB，因为 A 的虚拟地址对应的物理地址和 B 的不一样。
    
3. **用户态能改基址寄存器吗？** 绝对不能！这是特权指令，只有操作系统内核能改。
