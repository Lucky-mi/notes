# 可重入代码 (Reentrant Code)

## 1. 核心定义
允许多个进程同时访问，但是不允许被任何进程修改

**可重入代码**（也叫“纯代码” Pure Code）是指一段代码（函数），在被执行的过程中，如果**被中断**（比如时间片到了、硬件中断来了），然后**由另一个执行流再次进入**该代码执行。

- **结果**：两次执行都能得出正确的结果，互不干扰。
    
- **本质**：它**不保存任何状态**，或者说它的状态完全保存在**栈 (Stack)** 上，而不是全局数据区。
    

## 2. 为什么叫“可重入”？

想象你正在厨房切菜（执行函数）：

1. **不可重入**：你切了一半，把刀放在**公共案板**上。这时候你妈妈进来了（中断），她也要切菜，她拿起那把刀切了蒜。等你回来（恢复现场），发现刀上有蒜味，甚至刀被拿走了。这就乱了。
    
2. **可重入**：你切菜用的是你**自带的案板和刀**（栈变量）。你妈妈进来切菜，她也拿出她**自带的一套**。你们互不干扰，谁中断谁都没关系。
    

---

## 3. 判别标准：如何一眼看出代码是否可重入？ (考研必会)

如果一个函数满足以下条件，它就是可重入的：

1. **不使用全局变量**（或者 `static` 静态局部变量）。
    
2. **不修改代码本身**（self-modifying code，现在的 OS 都有内存保护，基本不会发生了）。
    
3. **只调用其他可重入函数**（如果你调用的 `printf` 是不可重入的，那你也被“污染”了）。
    
4. **所有数据都保存在栈上**（局部变量）或者**由调用者传入**。

## 4. 代码对比：一目了然

为了考研或面试，请务必记住这个经典的对比例子：

### (1) 不可重入代码 (危险!)
```c
int global_temp; // 全局变量：这就是罪魁祸首

void swap_bad(int *a, int *b) {
    global_temp = *a;  // 1. 把 a 存入全局变量
    // <--- 假设在这里发生了中断，另一个线程也调用了 swap_bad
    // 它会把 global_temp 修改掉！
    *a = *b;
    *b = global_temp;  // 2. 回来时，这里的 global_temp 已经是脏数据了
}
```

### (2) 可重入代码 (安全!)
```c
void swap_good(int *a, int *b) {
    int local_temp;    // 局部变量：存在栈里！
    // 每个线程都有自己独立的栈，所以每个线程都有自己独立的 local_temp
    local_temp = *a;   
    *a = *b;
    *b = local_temp;   // 无论怎么中断，我的栈别人碰不到
}
```

## 5. 易混概念：可重入 vs. 线程安全 (Thread-Safe)

这是 408 选择题中最喜欢挖坑的地方。它们**有交集，但不一样**。

|**维度**|**可重入 (Reentrant)**|**线程安全 (Thread-Safe)**|
|---|---|---|
|**定义**|代码可以被中断并在此时被再次调用。|多线程并发访问不会导致数据出错。|
|**手段**|**完全不使用共享数据** (主要靠栈)。|**使用锁 (Mutex/PV)** 来保护共享数据。|
|**关系**|**可重入代码一定是线程安全的。**|**线程安全代码不一定是可重入的。**|
|**例子**|`swap_good` (用局部变量)|`mutex_lock(); global++; mutex_unlock();`|

> [!WARNING] 为什么线程安全不等于可重入？
> 
> 假设一个函数用 互斥锁 变成了线程安全。
> 
> - Process A 拿到了锁，正在执行。
>     
> - 突然来了个 **中断 (Interrupt)**，中断处理程序（ISR）也想调这个函数。
>     
> - ISR 发现锁被 A 拿着，于是 ISR 等待锁释放。
>     
> - **死锁！** 因为 ISR 只有执行完，CPU 控制权才会还给 A，但 A 不执行完就没法释放锁。
>     
> - **结论**：这个函数虽然线程安全，但在中断环境下**不可重入**。
>

## 6. 现实中的例子

在 C 语言标准库中，很多老函数是不可重入的，后来出了 `_r` 后缀的版本。

- **`strtok`**: 不可重入。它内部用了一个 `static` 变量记录切分字符串切到哪了。多线程用它会乱套。
    
- **`strtok_r`**: 可重入。它要求调用者多传一个参数，用来手动保存状态。
    
- **`rand`**: 通常不可重入（依赖全局种子）。
    
- **`rand_r`**: 可重入。

## 7. 总结 (Obsidian Note)

- **核心特征**：无全局变量，无静态局部变量，数据全在栈上。
    
- **重要性**：**中断处理程序 (ISR)** 必须是可重入的。
    
- **口诀**：
    
    - 用全局变量 = 脏。
        
    - 加锁 = 线程安全，但可能不可重入。
        
    - 用局部变量 = 纯净，可重入。
