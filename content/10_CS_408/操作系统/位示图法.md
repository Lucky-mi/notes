### 1. 核心原理：一张“电影院选座图”

想象整个磁盘是一个巨大的电影院，每一个盘块就是一张椅子。

我们需要一张图来一眼看清哪里有人坐（占用），哪里是空的（空闲）。

#### A. 映射规则

- **基本单位**：用 **1个二进制位 (bit)** 对应磁盘上的 **1个盘块**。
    
- **标记约定**（考试要看清题意，通常如下）：
    
    - `0`：代表**空闲**（没人坐）。
        
    - `1`：代表**占用**（有人坐）。
        
- **组织方式**：计算机内存最小寻址单位通常是**字节 (8 bit)** 或 **字 (Word, 如 32 bit)**。所以我们把这些 bit 打包成一个个“字”。
    

#### B. 举个栗子 🌰

假设字长是 16位（1个字里有16个 0/1）。

- **字0**：`1 1 1 0 0 0 ...`
    
    - 第 1、2、3 位是 1 $\rightarrow$ 说明盘块 #0, #1, #2 被占用了。
        
    - 第 4 位是 0 $\rightarrow$ 说明盘块 #3 是空的！可以分配！

### 2. 两个核心操作：分配与回收

这比成组链接法简单多了，全是**逻辑运算**。

#### A. 分配 (Allocation)

你要申请 $k$ 个盘块：

1. **扫描**：OS 像雷达一样扫描位示图，寻找连续的 `0`（或者零散的 `0`）。
    
2. **计算**：找到一个 `0` 所在的位置（比如第 $i$ 行，第 $j$ 列），把它换算成**盘块号**。
    
3. **修改**：把位示图上对应的 `0` 改成 `1`。
    

#### B. 回收 (Deallocation)

你要归还盘块号 $b$：

1. **计算**：把盘块号 $b$ 换算成位示图的坐标（第 $i$ 行，第 $j$ 列）。
    
2. **修改**：把对应的 `1` 改成 `0`。

### 3. 🔥 必考：公式推导（计算题刺客）

这是你必须死记硬背，并且要灵活变通的部分。

**设定参数：**

- **$b$**：盘块号 (Block Number)
    
- **$w$**：字长 (Word Length)，即一行有多少个位。
    
- **$i$**：字号 (Word Number / 行号)。
    
- **$j$**：位号 (Bit Number / 列号)。
    

#### ⚔️ 场景一：最常见的“全 0 开始” (Standard)

> 假设：盘块号从 0 开始，字号从 0 开始，位号从 0 开始。

1. 已知 $(i, j)$ 求盘块号 $b$：
    
    $$b = i \times w + j$$
    
    (理解：前面已经完整过了 $i$ 行，每行 $w$ 个，所以是 $i \times w$，再加上当前的偏移量 $j$)
    
2. **已知盘块号 $b$ 求位置 $(i, j)$**：
    
    - 字号：$i = b \ // \ w$ （整除）
        
    - 位号：$j = b \ \% \ w$ （取余）
        

#### ⚔️ 场景二：坑人的“全 1 开始” (The Trap)

> 假设：盘块号从 1 开始，字号从 1 开始，位号从 1 开始。
> 
> 考研真题特别喜欢这么出，用来坑那些死背公式的人。

1. 已知 $(i, j)$ 求盘块号 $b$：
    
    $$b = (i - 1) \times w + j$$
    
    (理解：第 $i$ 行其实只过了 $i-1$ 个完整的行)
    
2. **已知盘块号 $b$ 求位置 $(i, j)$**：
    
    - 字号：$i = (b - 1) \ // \ w + 1$
        
    - 位号：$j = (b - 1) \ \% \ w + 1$
        
        (技巧：先把 $b$ 减 1 变回 0 进制算，算出来结果后再加 1 变回 1 进制)

### 4. 优缺点分析（简答题/选择题）

#### 优点 👍

1. **空间小**：1 TB 的硬盘，如果块大小 4KB，位示图只需要约 32MB 内存（$1\text{TB}/4\text{KB} = 2.5 \text{亿个 bit} \approx 30\text{MB}$）。
    
2. **找连续空间容易**：只要在位示图里看哪有一排 `0` 就行了。这对于连续分配或成组分配非常友好。
    

#### 缺点 👎

1. **大磁盘的压力**：如果是 16TB 的大硬盘，位示图可能达到几百 MB，常驻内存稍微有点心疼（虽然现在内存不值钱了）。
    
2. **扫描开销**：如果磁盘快满了（全是 1），找一个 0 需要扫描很久（虽然是内存操作，但也耗时）。
