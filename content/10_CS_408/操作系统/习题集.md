今有三个并发进程 R、M、P，它们共享了一个可循环使用的缓冲区 B，缓冲区 B 共有 N 个单元。进程 R 负责从输入设备读信息，每读一个字符后，把它存放在缓冲区 B 的一个单元中；进程 M 负责处理读入的字符，若发现读入的字符中有空格符，则把它改成“，”；进程 P 负责把处理后的字符取出并打印输出。当缓冲区单元中的字符被进程 P 取出后，则又可用来存放下一次读入的字符。请用 P、V 操作为同步机制写出它们能正确并发执行的程序。
### 题目分析

这不是简单的两个进程互斥，而是三个进程形成一条“流水线”：

1. **R (Reader)**：生产原始数据 $\rightarrow$ 放入缓冲区。
    
2. **M (Modifier)**：加工数据（空格变逗号） $\rightarrow$ 放入（其实是更新）缓冲区。
    
3. **P (Printer)**：消费最终数据 $\rightarrow$ 取出打印 $\rightarrow$ 腾空缓冲区。
    

**关键点：**

- **同步关系**：
    
    - M 必须等 R 放好数据才能处理（R $\rightarrow$ M）。
        
    - P 必须等 M 处理好数据才能打印（M $\rightarrow$ P）。
        
    - R 必须等 P 取走数据腾出空位才能再放（P $\rightarrow$ R）。
        
- **互斥关系**：
    
    - 在本题中，由于是流水线操作，R操作第 $i$ 个单元，M操作第 $i-1$ 个单元，P操作第 $i-2$ 个单元。在同步信号量的严格控制下，三个进程**不会同时访问同一个缓冲区单元**。
        
    - 因此，**通常不需要设置额外的 `mutex` 互斥信号量**来锁定整个缓冲区（设了反而会降低并发度，变成串行工作）。

### 完整的同步互斥伪代码

我们定义三个信号量来代表“资源的流转”：
```c
// 信号量定义
semaphore empty = N;      // 表示缓冲区有多少个空位可供 R 存放
semaphore full_for_M = 0; // 表示有多少个单元已存入数据，等待 M 处理
semaphore full_for_P = 0; // 表示有多少个单元已处理完毕，等待 P 打印

// 缓冲区及指针（模拟循环队列）
char B[N]; 
int in = 0;   // R 的存放指针
int mid = 0;  // M 的处理指针
int out = 0;  // P 的取出指针

// =======================
// 进程 R：负责读入
// =======================
void Process_R() {
    char x;
    while(TRUE) {
        // 1. 生产数据
        x = read_char(); 

        // 2. 申请空位
        P(empty); 

        // 3. 放入缓冲区
        B[in] = x;
        in = (in + 1) % N; // 移动指针

        // 4. 通知 M 可以处理了
        V(full_for_M); 
    }
}

// =======================
// 进程 M：负责加工
// =======================
void Process_M() {
    while(TRUE) {
        // 1. 等待 R 生产的数据
        P(full_for_M); 

        // 2. 加工数据（直接在缓冲区修改）
        if (B[mid] == ' ') {
            B[mid] = ',';
        }
        mid = (mid + 1) % N; // 移动指针

        // 3. 通知 P 可以打印了
        V(full_for_P); 
    }
}

// =======================
// 进程 P：负责打印
// =======================
void Process_P() {
    char y;
    while(TRUE) {
        // 1. 等待 M 处理完的数据
        P(full_for_P); 

        // 2. 取出并打印
        y = B[out];
        print(y);
        out = (out + 1) % N; // 移动指针

        // 3. 释放空位，通知 R 可以放新数据了
        V(empty); 
    }
}
```
