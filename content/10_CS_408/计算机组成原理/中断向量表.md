### 一、 核心定义：什么是中断向量表？

- **中断向量（Interrupt Vector）：** 其实就是中断服务程序（ISR）的**入口地址**。
    
- **中断向量表（IVT）：** 也就是把系统中所有的中断类型号（0~255）和它们对应的“入口地址”一一对应起来，存放在内存中的一块连续区域。
    

**一句话本质：** **IVT 是一个“数组”，下标是中断类型号，数组内容是函数指针（地址）。**

---

### 二、 经典模型：实模式下的 IVT（8086 体系）

在 408 考研的计组题目中，如果让你计算中断向量的地址，**默认通常是指 8086 实模式下的 IVT**。这个模型最简单、最经典。

#### 1. 存放位置

- 默认存放在内存的**最低端**：`0x00000` ~ `0x003FF`。
    
- **共占用 1KB** 的空间。
    

#### 2. 表的结构（考点！）

- **条目数量：** 支持 256 种中断（0号 ~ 255号）。
    
- **每个条目大小：** **4 字节**。
    
- **条目内容：** 存放的是长跳转地址（Segment:Offset）。
    
    - **低 2 字节：** 偏移地址（IP，Offset）。
        
    - **高 2 字节：** 段基址（CS，Segment）。
        

#### 3. 结构图解

内存地址从小到大排列：

Plaintext

```
地址      内容
-------  -----------------------
0x00000  [ 0号中断的 IP (低字节) ]  <-- 0号中断入口（除零错误）
0x00001  [ 0号中断的 IP (高字节) ]
0x00002  [ 0号中断的 CS (低字节) ]
0x00003  [ 0号中断的 CS (高字节) ]
-------  -----------------------
0x00004  [ 1号中断的 IP (低字节) ]  <-- 1号中断入口（单步调试）
...      ...
-------  -----------------------
0x00020  [ 8号中断的 IP ... ]       <-- 8号中断（时钟中断）
...      ...
```

### 三、 寻址机制：硬件是如何找到处理程序的？

这是硬件自动完成的动作，是**微程序**或**硬布线逻辑**实现的，速度极快。

假设 CPU 检测到了 **N 号中断**（例如 N=8，时钟中断）：

1. 计算表项地址（指针的指针）：
    
    由于每个表项占 4 字节，硬件自动将中断号 N 乘以 4。
    
    $$\text{IVT\_Entry\_Addr} = N \times 4$$
    
    - 例如：8号中断的表项地址 = $8 \times 4 = 32 = 0x0020$。
        
2. 取出入口地址（取数据）：
    
    CPU 访问内存地址 0x0020，连续读取 4 个字节。
    
    - 从 `0x0020` 取出 **IP**（新 PC）。
        
    - 从 `0x0022` 取出 **CS**。
        
3. **跳转执行（加载 PC）：**
    
    - 硬件将取出的 IP 赋值给 PC 寄存器。
        
    - 硬件将取出的 CS 赋值给 CS 寄存器。
        
    - **下一条指令，CPU 就直接飞到了中断服务程序里去了。**

### 四、 进阶演变：保护模式下的 IDT（现代 OS）

考研中如果涉及到**操作系统**的深层原理（尤其是 Linux/Windows 内核），你必须知道 IVT 已经进化了。

在现代 CPU（保护模式/64位模式）下，内存不仅仅是地址，还包含**权限（Privilege）**。简单的 IVT 无法提供安全性（比如防止用户态程序乱跳进内核）。

- **新名字：** **中断描述符表（IDT, Interrupt Descriptor Table）**。
    
- **区别 1（位置）：** 不再固定在内存 0 地址，而是由 **IDTR 寄存器** 指向任意内存位置。
    
- **区别 2（大小）：** 每个表项（称为“门描述符”）通常是 **8 字节**（32位系统）或 **16 字节**（64位系统）。
    
- **区别 3（内容）：** 里面不光有地址，还有**属性位（DPL）**。
    
    - **权限检查：** CPU 在查表时，会对比当前特权级（CPL）和中断门的特权级（DPL）。如果权限不够（例如用户态试图调用内核专用的中断），CPU 会抛出“保护性异常”（General Protection Fault, #GP）。
        

> 408 避坑指南：
> 
> 除非题目明确提到“保护模式”或“IDT”，否则在做计算题（如“某中断向量地址为多少”）时，默认按 8086 实模式（IVT，每项4字节）计算。

### 五、 408 考研实战：怎么考？

这一块的考点通常非常“硬核”，主要集中在计组的大题或选择题中。

#### 题型 1：地址计算（送分题，必须拿满）

题目： 若中断向量表中，中断类型号为 0x20 的中断服务程序的入口地址存放在哪里？

解题思路：

1. 中断号 $N = 0x20$（十六进制）。
    
2. 表项地址 = $N \times 4$。
    
3. $0x20 \times 4 = 0x80$。
    
    答案： 该中断向量存放在内存地址 0x00080 开始的 4 个字节单元中。
    

#### 题型 2：中断向量 vs 中断向量地址（文字游戏）

这是选择题最爱设的陷阱，请务必区分：

- **中断向量（Interrupt Vector）：** 是**值**。即中断服务程序的入口地址（CS:IP）。
    
- **中断向量地址（Address of Vector）：** 是**指针**。即这个入口地址存放在内存中的位置（IVT 中的索引位置）。
    

关系公式：

$$(中断向量地址) \xrightarrow{\text{访存取值}} (中断向量/入口地址)$$

#### 题型 3：中断处理过程的硬件/软件分工

问： 查询中断向量表这一步，是谁做的？

答： 硬件（CPU）。在中断响应周期（Interrupt Acknowledge Cycle），CPU 根据中断控制器发来的向量号，自动查表并加载 PC。这不是操作系统软件写的代码，而是 CPU 内部电路完成的。

### 总结一张图（脑海中构建）

想象内存最底部（`0x0000`）有一排柜子：

- **柜子编号**：0, 1, 2 ... 255（中断类型号）。
    
- **柜子大小**：每个柜子宽 4 厘米（4 字节）。
    
- **柜子里面**：装着一张纸条，写着“某某部门的地址”（CS:IP）。
    

**当 CPU 收到 3 号中断（Debug Breakpoint）时：**

1. 走到 3 号柜子（$3 \times 4 = 12$ 字节处）。
    
2. 拿出纸条。
    
3. 直接瞬移到纸条上写的地址去执行代码。
