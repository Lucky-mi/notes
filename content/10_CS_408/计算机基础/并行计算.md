### OpenMP
采用fork-join并行执行模式，利用线程池技术
归约reduction 最好用来并行相加
```c
int sum = 0;
// 告诉 OpenMP：
// 1. 给每个线程创建一个私有的 sum 副本 (初始化为 0)
// 2. 循环时，每个线程累加到自己的私有副本上
// 3. 循环结束后，把所有线程的私有副本的值，安全地“加”到
//    主线程的原始 sum 变量上

#pragma omp parallel for reduction(+: sum)
for (int i = 0; i < 1000; i++) {
    sum = sum + 1; // 这里操作的是线程私有的 sum
}
printf("Sum = %d\n", sum); // 结果正确 (1000)，而且速度飞快！
```
