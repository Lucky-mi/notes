### 一、 为什么需要 STP？（解决环路问题）

在交换机组成的以太网中，为了可靠性，我们通常会把网线连成环状（备份链路）。比如 A 连 B，B 连 C，C 又连回 A。

**物理环路带来的三大灾难**：

1. **广播风暴 (Broadcast Storm)**：广播帧在环路里无限转圈，带宽瞬间被占满，网络瘫痪。
    
2. **MAC 地址表震荡 (MAC Table Instability)**：交换机一会儿看到同一个 MAC 地址从接口 1 传来，一会儿又从接口 2 传来，导致 MAC 表一直在变，无法正确转发。
    
3. **重复帧 (Duplicate Frames)**：目的主机会收到多份一模一样的数据。
    

**STP 的作用**： 在物理上有环路的情况下，通过软件算法，**逻辑上阻塞（Block）** 某些接口，把“环”剪断，修剪成一棵**无环的树**。

- 当主链路断了，STP 会自动把刚才阻塞的接口打开，恢复通信（备份作用）。

### 二、 STP 的“选举游戏” (核心考点)

STP 的工作过程就是交换机之间不断互发 **BPDU (Bridge Protocol Data Unit)** 报文，进行 PK 的过程。

**PK 的终极口诀（408 必背 4 步）：**

> **比小不比大！谁小谁当老大！**

比较顺序严格如下（只有上一条一样，才比下一条）：

1. **根网桥 ID (Root Bridge ID)**：看谁是老大。
    
2. **根路径开销 (Root Path Cost)**：看离老大有多远。
    
3. **发送者网桥 ID (Sender Bridge ID)**：看上级是谁（邻居是谁）。
    
4. **发送者端口 ID (Sender Port ID)**：看连接的接口编号。
    

---

### 三、 详细选举步骤（手把手教你做题）

假设网络里有几台交换机连成一团。STP 启动后，会按顺序进行以下 3 步选举：

#### 第一步：选出唯一的“根网桥” (Root Bridge, RB)

- **规则**：全网 **网桥 ID (Bridge ID)** 最小的交换机当选。
    
- **网桥 ID 构成** = `优先级 (2字节)` + `MAC 地址 (6字节)`。
    
    - 默认优先级都是 32768。
        
    - 所以通常 **MAC 地址最小** 的那个交换机就是根网桥（老大）。
        
- **地位**：树根。根网桥上的所有接口永远是**指定端口 (DP)**，处于转发状态，绝不会被阻塞。
    

#### 第二步：给每个“非根网桥”选一个“根端口” (Root Port, RP)

- **含义**：非根网桥（小弟）要找一条**去往根网桥（老大）最近的路**。这个接口就叫根端口。
    
- **数量**：每个非根网桥 **只能有 1 个** RP。
    
- **PK 规则**（依次比）：
    
    1. **比较根路径开销 (Cost)**：带宽越大，Cost 越小（10Gbps < 1Gbps < 100Mbps）。离根越近越好。
        
    2. **比较对端（上游）网桥 ID**：如果你有两根线分别连着 Switch B 和 Switch C，且开销一样，那就看 B 和 C 谁的 ID 小。
        
    3. **比较对端（上游）端口 ID**：如果两根线都连着同一台交换机（比如两根线连 Switch B），那就看 Switch B 那边的接口编号谁小。
        

#### 第三步：给每条网线（网段）选一个“指定端口” (Designated Port, DP)

- **含义**：每条连线（冲突域/网段）必须有一个负责人，负责把数据转发到根网桥方向。
    
- **规则**：谁离根近，谁就是 DP。
    
    - 根网桥上的接口都是 DP。
        
    - 对于两个非根交换机之间的连线：比较它们谁离根更近（Cost 小 -> ID 小）。赢的那一头是 DP，输的那一头就被阻塞。
        

#### 第四步：剩下的接口全部“阻塞” (Blocking)

- 既不是根端口 (RP)，也不是指定端口 (DP) 的接口，就是**预备端口 (AP/NDP)**。
    
- **状态**：逻辑断开，不转发数据，只接收 BPDU 监听网络变化。

### 四、 图解示例 (脑补一下)

假设有三台交换机连成三角形：S1 (MAC: 10), S2 (MAC: 20), S3 (MAC: 30)。

1. **选根**：S1 的 MAC 最小 (10)，**S1 是根网桥**。
    
2. **选 RP**：
    
    - S2 去 S1：直接连最快。连接 S1 的口是 RP。
        
    - S3 去 S1：直接连最快。连接 S1 的口是 RP。
        
3. **选 DP**：
    
    - S1-S2 链路：S1 是根，S1 侧是 DP。
        
    - S1-S3 链路：S1 是根，S1 侧是 DP。
        
    - **关键是 S2-S3 这条链路**：谁当 DP？
        
        - S2 离根距离（Cost）和 S3 离根距离一样（假设都是直连）。
            
        - 比 ID：S2 (20) < S3 (30)。
            
        - 所以 S2 赢了。S2 连接 S3 的那个口是 **DP**。
            
4. **阻塞**：
    
    - S3 在 S2-S3 链路上的那个口，既不是 RP 也不是 DP，**阻塞 (Block)**！
        
    - 这就切断了环路。

### 五、 STP 端口状态 (408 选择题小考点)

虽然选举讲完了，但端口不是“啪”一下就变通的，它有过渡状态（防止环路）：

1. **Disabled (禁用)**：端口没插线或被管理员关了。
    
2. **Blocking (阻塞)**：也就是刚才输掉的端口。**只收 BPDU，不发 BPDU，不传数据，不学 MAC。**
    
3. **Listening (监听)**：正在选举中。**收发 BPDU，不传数据，不学 MAC。**
    
4. **Learning (学习)**：选举结束，准备干活。**收发 BPDU，开始学习 MAC 地址表，但不传数据。** (为了防止大量未知单播泛洪)。
    
5. **Forwarding (转发)**：正常工作。**什么都干。**
    

> **RSTP (快速生成树)** 的改进：把 5 种状态简化为 3 种 (Discarding, Learning, Forwarding)，大大加快了收敛速度（从 30-50秒 缩短到 几秒甚至毫秒）。


## 简述

## 1. 核心目的
* **消除环路**：防止广播风暴、MAC 表震荡。
* **链路备份**：主链路断开后，阻塞接口自动恢复。

## 2. 选举四步法 (Golden Rules)
所有比较原则均为：**数值越小越优先**。

1.  **选根网桥 (Root Bridge)**
    * 依据：**Bridge ID (优先级 + MAC)**。
    * 结果：全网只有一个根，根的所有接口均为**指定端口 (DP)**且处于转发状态。
2.  **选根端口 (Root Port, RP)**
    * 对象：**每一个非根交换机**必须选且只能选 1 个。
    * 标准：
        1.  到根的路径开销 (Path Cost) 最小。
        2.  对端网桥 ID (Sender BID) 最小。
        3.  对端端口 ID (Sender PID) 最小。
3.  **选指定端口 (Designated Port, DP)**
    * 对象：**每一个网段 (Segment)** 必须选 1 个。
    * 标准：同上 (看谁离根更近，或者谁的 ID 更小)。
4.  **阻塞端口 (Alternate/Blocking Port)**
    * 既不是 RP 也不是 DP 的端口，进入阻塞状态。

## 3. BPDU 报文
* 交换机之间通过发送 BPDU (Bridge Protocol Data Unit) 交换信息。
* 默认每 **2秒** 发一次。

## 4. 端口状态流转 (STP vs RSTP)
| STP 状态 | 功能 | RSTP 对应状态 |
| :--- | :--- | :--- |
| Disabled | 不工作 | Discarding |
| Blocking | **只收 BPDU** | Discarding |
| Listening | 选出根/RP/DP | Discarding |
| Learning | **开始学 MAC** | Learning |
| Forwarding | **正常转发** | Forwarding |

## 5. 做题技巧
遇到 STP 拓扑题：
1.  先找 **MAC 最小** 的交换机 -> 标为 **Root**。
2.  把 Root 的所有接口标为 **DP (√)**。
3.  在其他交换机上，找离 Root 最近的口 -> 标为 **RP (↑)**。
4.  在剩下的连线上，比较两端谁离 Root 近/谁 ID 小 -> 赢的标 **DP (√)**，输的标 **Block (×)**。
