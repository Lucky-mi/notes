- **地位：** ICMP 属于 **网络层** 协议。
- **关系：** 它虽然是网络层协议，但是它的报文是**封装在 IP 数据报**中传输的。（所以说ip直接为icmp提供服务） #错题
    - _形象比喻：_ 就像 IP 是一个大信封，ICMP 是信封里的一张特殊的小纸条，用来告诉发信人“查无此人”或者“信件已送达”。
- **作用：** 为了提高 IP 数据报交付成功的机会。主要功能是**报告差错**和**询问信息**。
### 重要应用：
#### ① Ping (Packet Internet Groper)
- **原理：** 使用 ICMP **Echo Request (Type 8)** 和 **Echo Reply (Type 0)**。(请求回答报文)  #错题 
- **层级：** Ping 是**应用层**程序，但它直接使用**网络层**的 ICMP。**它没有使用 TCP 或 UDP**。
- **过程：** A 向 B 发 Request，B 收到后原封不动把数据返还给 A (Reply)。A 计算往返时间 (RTT)。
#### ② Traceroute (Windows 下叫 tracert)
它的作用是跟踪数据包从源到目的经过了哪些路由器。
让发送的UDP用户数据报故意用一个非法的UDP端口，ICMP返回“端口不可达”差错报文
- **核心原理：利用 TTL (Time To Live) 字段 + ICMP 时间超过报文。**
- **详细流程：**
    1. 源主机发送一连串 IP 数据报，封装的是无法交付的 UDP 端口（Linux）或 ICMP Echo Request（Windows）。
    2. **第一轮：** 将 TTL 设置为 1。到达第 1 个路由器时，TTL 减为 0，路由器丢包，并回送 **ICMP 时间超过 (Type 11)** 报文。源主机收到后，知道了第 1 个路由器的 IP。
    3. **第二轮：** 将 TTL 设置为 2。经过第 1 个路由器（TTL变1），到达第 2 个路由器时 TTL 变 0，回送 ICMP 时间超过。源主机知道了第 2 个路由器的 IP。
    4. **...循环...**
    5. **终局：** 当数据报终于到达**目的主机**时，TTL 还没耗尽。
        - 如果是 Linux (UDP)：目的主机发现端口没人听，回送 **ICMP 端口不可达 (Type 3, Code 3)**。
        - 如果是 Windows (ICMP)：目的主机回送 **ICMP Echo Reply**。
    6. 源主机收到这两个特定的报文之一，就知道“到站了”，停止探测。
### 关于返回的是端口不可达还是时间超过报文？
具体来说：

1. **ICMP 时间超过报文 (Time Exceeded)**
    
    - **来源**：**路径上的中间路由器**。
        
    - **原因**：Traceroute 发出的探测包（不论是 UDP 还是 ICMP Echo）的 TTL（生存时间）在传输过程中减为 0。路由器丢弃该包，并向源主机发送“时间超过”报文。
        
    - **作用**：用来**探测中间每一跳路由器的 IP 地址**。
        
2. **ICMP 端口不可达差错报文 (Port Unreachable)**
    
    - **来源**：**目的主机（终点）**。
        
    - **原因**：这是 **Linux/Unix 系统（以及 Cisco 设备）** 默认的 Traceroute 实现方式。它发送的是 **UDP 数据报**，且目的端口号是一个**不可达的高端口号**（通常大于 30000）。
        
    - **过程**：当数据报终于到达目的地时，TTL 即使未过期，目的主机也会解包。但因为它没有程序监听那个高端口，所以它会丢弃数据报，并回送一个“ICMP 端口不可达”报文。
        
    - **作用**：**标志着 Traceroute 探测的结束**。源主机收到这个报文，就知道“我到达终点了”。

### 详细对比（考点总结）

|**报文类型**|**发送者**|**触发条件**|**含义**|
|---|---|---|---|
|**ICMP 时间超过** (Type 11)|**中间路由器**|TTL 减为 0|“我还没到终点，但我还在路上，这是我的 IP。”|
|**ICMP 端口不可达** (Type 3, Code 3)|**目的主机**|UDP 端口未开放|“我就是终点，但我没开这个端口，探测结束。”|

### 注意：Windows 的特例 (`tracert`)

虽然考研通常考上述的 UDP 实现（即标准 Traceroute），但你需要知道 **Windows 的 `tracert` 命令**实现方式略有不同：

- 它使用的是 **ICMP Echo Request**（类似于 Ping），而不是 UDP。
    
- **中间路由器**：依然回送 **“ICMP 时间超过”**。
    
- **目的主机**：回送 **“ICMP Echo Reply”**（回显应答），而不是“端口不可达”。
    

总结建议：

如果题目没有特别说明系统环境，通常默认指 UDP 实现的 Traceroute。

所以标准回答是：中间路由器返回“时间超过”报文，目的主机返回“端口不可达”报文。
