### 1. 符号与定义 (Identity)

- **常见符号**：$\text{arsinh } x$ 或 $\sinh^{-1} x$
    
    - _注：考研试卷中通常直接考察其**对数形式**，或者作为$\frac{1}{\sqrt{x^2+1}}$的原函数出现。_
        
- **定义**：它是双曲正弦函数 $y = \sinh x = \frac{e^x - e^{-x}}{2}$ 的反函数。
    

### 2. 对数形式 (⭐⭐⭐ 最核心考点)

这是**必须背诵**的公式，因为考研经常要求你把反双曲函数转化为对数形式来处理，或者直接考这个积分公式。

$$\text{arsinh } x = \ln(x + \sqrt{x^2+1})$$

- **记忆技巧**：
    
    - 因为 $\sinh x$ 涉及 $e^x$，所以它的反函数一定涉及 $\ln$。
        
    - 根号里是加号 $\sqrt{x^2+1}$（对应 $\sinh$ 的导数分母）。
        
    - 定义域是 $(-\infty, +\infty)$，所以 $x$ 可以取任何值，$\sqrt{x^2+1} > |x|$，保证真数恒正。
        

---

### 3. 导数与积分 (Calculus Tools)

#### A. 导数 (Derivative)

$$(\text{arsinh } x)' = \frac{1}{\sqrt{x^2+1}}$$

- **考研应用**：如果题目让你对 $\ln(x+\sqrt{x^2+1})$ 求导，不要硬用对数法则算，直接写出答案 $\frac{1}{\sqrt{x^2+1}}$ 能节省大量时间。
    

#### B. 积分公式 (Standard Integral)

这是不定积分中**最重要**的公式之一（被称为“长对数”）：

$$\int \frac{1}{\sqrt{x^2+a^2}} dx = \ln(x + \sqrt{x^2+a^2}) + C$$

- **注意**：这里可以直接写 $\text{arsinh}(x/a)$，但考研标准答案通常写对数形式。
    
- **对比**：
    
    - $\int \frac{1}{\sqrt{1-x^2}} dx = \arcsin x$ (分母是 $1-x^2$)
        
    - $\int \frac{1}{\sqrt{x^2+1}} dx = \ln(x+\sqrt{x^2+1})$ (分母是 $x^2+1$)
        
    - $\int \frac{1}{\sqrt{x^2-1}} dx = \ln|x+\sqrt{x^2-1}|$ (这是反双曲余弦，分母是 $x^2-1$)
        

---

### 4. 图像与性质 (Properties)

- **奇偶性**：**奇函数**。
    
    - $\text{arsinh}(-x) = -\text{arsinh}(x)$
        
    - 图像关于原点对称。
        
- **单调性**：在 $(-\infty, +\infty)$ 上**单调递增**。
    
- **定义域**：$(-\infty, +\infty)$。
    
- **值域**：$(-\infty, +\infty)$。
    

---

### 5. 泰勒展开 (Taylor Series) - 极限杀手锏

在求极限（例如 $\lim_{x\to 0}$）时，如果出现这个函数，用泰勒展开是最快的。

$$\text{arsinh } x = x - \frac{1}{2}\cdot\frac{x^3}{3} + \frac{1\cdot 3}{2\cdot 4}\cdot\frac{x^5}{5} - \cdots \quad (|x|<1)$$

- **规律**：形式非常像 $\arcsin x$，但是 $\arcsin x$ 也是奇函数且系数全是**正**的；而 $\text{arsinh } x$ 系数是**正负交替**的（一正一负）。
    
- 低阶近似（常用）：
    
    $$\text{arsinh } x \sim x - \frac{x^3}{6}$$
    
    (对比：$\arcsin x \sim x + \frac{x^3}{6}$，$\tan x \sim x + \frac{x^3}{3}$，$\arctan x \sim x - \frac{x^3}{3}$)
    

---

### 6. 考研易混淆点 (Trap!)

请务必区分以下三组，考场上紧张容易看错符号：

|**函数**|**导数形式**|**积分结果 (原函数)**|**备注**|
|---|---|---|---|
|**反正弦** $\arcsin x$|$\frac{1}{\sqrt{1-x^2}}$|$\arcsin x$|根号内常数在前面|
|**反双曲正弦** $\text{arsinh } x$|$\frac{1}{\sqrt{x^2+1}}$|$\ln(x+\sqrt{x^2+1})$|根号内是加号|
|**反双曲余弦** $\text{arcosh } x$|$\frac{1}{\sqrt{x^2-1}}$|$\ln(x+\sqrt{x^2-1})$|根号内变量在前面，且是减号|

---

### 总结给你的“复习小纸条”

1. **看到** $\int \frac{dx}{\sqrt{x^2+a^2}}$，**马上反应** $\ln(x+\sqrt{x^2+a^2})$。
    
2. **求极限**遇到 $\ln(x+\sqrt{x^2+1})$，**马上替换**为 $x - \frac{x^3}{6}$。
    
3. **求导** $\ln(x+\sqrt{x^2+1})$，**直接写** $\frac{1}{\sqrt{x^2+1}}$，不要犹豫。
