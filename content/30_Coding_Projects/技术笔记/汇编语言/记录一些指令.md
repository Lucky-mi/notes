```cpp
mov ecx, [rbp-20]        ; ecx = 参数x
movsx rax, ecx           ; 符号扩展到64位
imul rax, 1431655766     ; 0x55555556，等价于 x * (2^32 / 3) 的近似值
shr rax, 32              ; 取高32位结果
sar edx, 31              ; edx = x的符号位（x为负数时edx=-1，否则0）
sub eax, edx             ; 调整结果，得到x/3的近似值
mov edx, eax
add edx, edx             ; edx = 2*(x/3)
add edx, eax             ; edx = 3*(x/3)
sub eax, ecx, edx        ; eax = x - 3*(x/3) = x % 3
```

**rbp（栈帧基址指针）**：

1. `rbp` 通常用于指向当前函数的栈帧的基址，也就是局部变量和函数参数的起始位置。它指向了当前函数的局部数据存储区。
2. 在函数开始时，通常会通过 `push %rbp` 将 `rbp` 的值保存到栈上，然后通过 `mov %rsp, %rbp` 将 `rsp` 的值赋给 `rbp`，从而建立了一个新的栈帧。
3. 在函数结束时，通常会通过 `leave` 或 `leaveq` 指令来清理栈帧并还原 `rbp` 的值，以恢复到调用函数的栈帧。这使得函数能够正确返回并保持栈的一致性。

**rsp（栈指针）**：

1. `rsp` 指向了当前栈顶的地址。它用于跟踪栈上的数据的位置，包括函数的返回地址和局部变量。
2. 在函数调用时，通过将数据压入栈中（使用 `push` 指令）来分配空间，`rsp` 的值会递减，将数据推入栈中。
3. 在函数返回时，通过从栈中弹出数据（使用 `pop` 指令）来释放栈上的空间，`rsp` 的值会递增，将数据弹出栈。
4. `rsp` 寄存器的值也会在函数调用和返回过程中被保存和恢复，以确保栈的正确管理。
