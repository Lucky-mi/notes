## 双指针
### 1. 对撞指针 (Collision Pointers)

核心逻辑：

两个指针 left 和 right 分别指向序列的头部和尾部，向中间逼近，直到满足条件或相遇。

**适用场景**：

- **有序数组**的查找问题（如：两数之和 II）。
    
- **字符串**反转、回文串判断。
    
- **盛水容器**类问题（求面积最大）。

```cpp
// 伪代码模板
int left = 0;
int right = nums.size() - 1;

while (left < right) {
    // 1. 根据当前 left 和 right 的值计算结果
    int current_val = calculate(nums[left], nums[right]);

    // 2. 根据结果决定移动哪个指针
    if (current_val == target) {
        return result;
    } else if (current_val < target) {
        left++; // 值太小，左边右移变大
    } else {
        right--; // 值太大，右边左移变小
    }
}
```

- **经典例题**：
    
    - LeetCode 167. 两数之和 II (输入有序数组)
        
    - LeetCode 11. 盛最多水的容器
        
    - LeetCode 125. 验证回文串

### 2. 快慢指针 (Fast & Slow Pointers)

核心逻辑：

两个指针 slow 和 fast 起点相同（或相差一步），fast 移动速度快（或先行），slow 移动慢。

**适用场景**：

- **链表问题**：判断链表是否有环、寻找链表中点、寻找倒数第 K 个节点。
    
- **原地修改数组**：去重、移除指定元素（`slow` 维护有效数据的边界，`fast` 负责探索）。
    

```cpp
// 场景：原地移除数组元素 / 链表判环
int slow = 0;
for (int fast = 0; fast < nums.size(); fast++) {
    // 1. 判断 fast 指向的元素是否是我们需要的
    if (nums[fast] != val) {
        // 2. 如果是需要的，这就放入 slow 的位置，并扩充 slow
        nums[slow] = nums[fast];
        slow++;
    }
    // fast 继续向前探索
}
return slow; // 返回新长度
```

- **经典例题**：
    
    - LeetCode 141. 环形链表 (Floyd 判圈算法)
        
    - LeetCode 26. 删除有序数组中的重复项
        
    - LeetCode 876. 链表的中间结点

### 3. 滑动窗口 (Sliding Window)

核心逻辑：

这是同向双指针的一种。维护一个窗口 [left, right]，right 主动向右扩展寻找可行解，left 被动向右收缩以优化解（求最短）或维持合法性。

**适用场景**：

- 求解**连续**子数组、子串的最大/最小长度、和、乘积等。


```cpp
// 滑动窗口通用模板
int left = 0, right = 0;
while (right < s.size()) {
    // 1. 扩大窗口：加入 right 对应的元素
    window.add(s[right]);
    right++;

    // 2. 判断是否需要收缩窗口 (while 或 if)
    while (window needs shrink) {
        // 3. 缩小窗口：移除 left 对应的元素
        window.remove(s[left]);
        left++;
    }
    
    // 4. 更新答案 (根据题目要求，可能在扩窗后，也可能在缩窗后)
    updateResult();
}
```

- **经典例题**：
    
    - LeetCode 209. 长度最小的子数组
        
    - LeetCode 3. 无重复字符的最长子串
        
    - LeetCode 76. 最小覆盖子串 (Hard，但非常经典)

### 💡 总结表格 

|**模式**|**指针方向**|**核心动作**|**典型应用**|**时间/空间**|
|---|---|---|---|---|
|**对撞指针**|$\rightarrow \dots \leftarrow$|左加右减|二分查找变种、反转、两数之和|$O(n) / O(1)$|
|**快慢指针**|$\rightarrow \dots \rightarrow$|快跑慢跟|链表找环/中点、数组原地去重|$O(n) / O(1)$|
|**滑动窗口**|$\rightarrow [ \dots ] \rightarrow$|右扩左缩|连续子串/子数组的最值问题|$O(n) / O(1)$|
|**合并指针**|$\rightarrow \dots \rightarrow$|谁小移谁|归并排序、合并有序链表|$O(n+m) / O(1)$|
